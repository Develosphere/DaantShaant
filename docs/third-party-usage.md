# DaantShaant Third-Party Usage

Statuses describe the current runtime after Phase 6 Fast Track.

| Technology | Status | Usage |
|---|---|---|
| Supabase PostgreSQL | **ACTIVE - SOLE DATABASE** | Managed PostgreSQL hosting |
| SQLAlchemy 2 | **ACTIVE** | Provider-neutral async ORM/repository layer |
| asyncpg | **ACTIVE** | PostgreSQL async driver |
| Alembic | **ACTIVE** | PostgreSQL schema migrations |
| Argon2-cffi | **ACTIVE** | Argon2id password hashing |
| PyJWT | **ACTIVE** | Short-lived access JWTs |
| MongoDB | **REMOVED** | No application runtime usage |
| motor / pymongo / bson | **REMOVED** | Dependencies and ObjectId semantics removed |
| bcrypt | **REMOVED** | Replaced by Argon2id |
| Next.js 14 / React 18 | **ACTIVE** | Web application |
| FastAPI / Uvicorn | **ACTIVE** | API and service runtime |
| Pydantic v2 | **ACTIVE** | API schemas and configuration |
| httpx | **ACTIVE** | Service-to-service HTTP, direct Qwen/Gemini vision REST calls, and Overpass/Nominatim geodata calls (no SDKs) |
| Gemini | **ACTIVE (fallback)** | Recommendation embeddings still call Gemini directly. Since 2A.4 `GeminiProvider` is the orchestrator gateway FALLBACK (chat text, product descriptions, recommendation reranking/final message). Since 2C it is ALSO the Teeth Analyzer clinical-vision TECHNICAL FALLBACK, service-local over plain httpx `v1beta` `generateContent` (the `google-generativeai` SDK dependency was removed from the analyzer). No Google SDK introduced anywhere |
| OpenRouter | **REMOVED - PROJECT-WIDE (ZERO active runtime references)** | Removed from orchestrator business text-generation paths (2A.5a–2A.5c). `llm_provider.py` and `openrouter_client.py` deleted. Phase 2C removed the last consumer - Teeth Analyzer clinical vision: `services/teeth_analyzer/src/teeth_analyzer/backends/openrouter.py` deleted and `TEETH_ANALYZER_OPENROUTER_API_KEY`/`_MODEL` config dropped. Only historical doc mentions and a test asserting its absence remain. PERMANENTLY ABANDONED |
| LangGraph / langchain-core | **ACTIVE** | Unified clinical screening pipeline orchestration (Phase 4-lite); product and dentist recommendation graphs (Phase 6 Fast Track). Pure deterministic orchestration — no patient data sent externally by LangGraph itself |
| FAISS / sentence-transformers / Hugging Face Hub | **REMOVED - PROJECT-WIDE (ZERO active runtime dependencies)** | Completely removed in Phase 12A Final. Replaced with DaantShaant Central Dentist Structured RAG (direct SQL/repo queries for patient scans, appointments, dentists) and curated deterministic keyword oral health knowledge lookup. Zero embeddings, zero vector stores, zero PyTorch overhead, zero HF network downloads. |
| OpenCV / Pillow | **ACTIVE** | Image processing |
| Google Maps / Places / Geocoding | **REMOVED - PROJECT-WIDE (ZERO active runtime callers)** | Phase 6 Fast Track removed Google Maps JS, Google Places API, and Google Geocoding API from active runtime paths. Replaced with OpenStreetMap, Overpass API, MapLibre GL JS, OpenFreeMap, and browser geolocation |
| OpenStreetMap / Overpass API | **ACTIVE** | Discover nearby dental clinics and practices from public OSM geodata (`amenity=dentist`, `healthcare=dentist`). Only search coordinates and radius are transmitted; NO patient clinical data is sent. Fallback: PostgreSQL registered platform dentists |
| MapLibre GL JS | **ACTIVE** | Client-side open-source vector map rendering for interactive dentist recommendation maps |
| OpenFreeMap | **ACTIVE** | Public vector map tile service and Liberty style source for MapLibre client-side map rendering |
| OpenStreetMap / Nominatim | **ACTIVE** | Lightweight geocoding and address suggestion lookup for PK/UAE location search with DaantShaant User-Agent |
| Foursquare Places API | **OPTIONAL RUNTIME** | Optional secondary clinic discovery provider (`categories=15007,15008`). Active only if `FOURSQUARE_API_KEY` is configured; skipped safely when unconfigured. Transmits only coordinates and search radius (no patient clinical data). Provider errors isolated from primary Overpass/PostgreSQL runtime |
| Geoapify Places API | **OPTIONAL RUNTIME** | Optional tertiary clinic discovery provider (`categories=healthcare.dentist`). Active only if `GEOAPIFY_API_KEY` is configured; skipped safely when unconfigured. Transmits only coordinates and search radius (no patient clinical data). Provider errors isolated from primary Overpass/PostgreSQL runtime |
| Alibaba Model Studio / Qwen | **ACTIVE (text generation primary)** | Shared primary AI gateway for conversational chat, product descriptions, recommendation explanations, and Phase 11A text-only patient-friendly screening report generation. Multimodal vision input removed from normal perception path in Phase 11A. Phase 12D provider freeze: `qwen3.7-flash` (thinking disabled) selected as canonical primary chat model after verified live benchmark (18/18 success, ~789ms avg latency). Clinical report generation remains unchanged on standard gateway (`qwen3.7-plus`, 60s timeout). Configuration: `CHAT_LLM_PROVIDER=qwen`, `CHAT_QWEN_MODEL=qwen3.7-flash`, `CHAT_QWEN_ENABLE_THINKING=false`, `CHAT_FALLBACK_PROVIDER=gemini`, `CHAT_GEMINI_MODEL=gemini-flash-lite-latest`. |
| DentalTensor Vision v1.0 (Ultralytics YOLO11n) | **ACTIVE - PRODUCTION PERCEPTION PRIMARY** | Custom oral pathology perception model conceived and developed by **Nathan Asif** for DaantShaant. Local YOLO11n object detector in Teeth Analyzer service (`teeth_analyzer/yolo_detector.py`) for visual oral pathology perception (calculus -> tartar, caries -> cavity_suspect, gingivitis -> gingivitis_signs, tooth discoloration -> discoloration, ulcer -> oral_ulcer). Branded runtime checkpoint: `dentaltensor_nathan_asif_v1.pt` (`YOLO_DENTAL_MODEL_PATH=services/teeth_analyzer/models/oral_disease/dentaltensor_nathan_asif_v1.pt`); checkpoints `best_v2.pt` and `best.pt` retained for rollback. CPU-capable inference, no external model server or cloud runtime dependency. Calibrated engineering screening thresholds: calculus 0.35, caries 0.55, gingivitis 0.50, discoloration 0.65, ulcer 0.65 (global fallback 0.50). Model card: `docs/dentaltensor-model-card.md` |
| Roboflow Universe oral-disease dataset | **OFFLINE TRAINING ASSET (CC BY 4.0)** | Task-specific training dataset (URL: https://universe.roboflow.com/di-qidb9/oral-disease-tabrb, 10,698 images, CC BY 4.0, classes: calculus, caries, gingivitis, tooth discoloration, ulcer). Trained offline on Modal (20 epochs) to produce `best.pt`. Note: dataset page does not publish detailed clinical labeling/provenance descriptions; model outputs represent screening observations, NOT a licensed definitive diagnosis |
| Roboflow Universe Dental Data Set | **OFFLINE TRAINING ASSET (CC BY 4.0)** | Auxiliary healthy negative training candidate source (URL: https://universe.roboflow.com/nathan-asif-blm21/dental-data-set-tta0w/dataset/dataset, workspace: `nathan-asif-blm21`, project: `dental-data-set-tta0w`, version: `dataset`, license: CC BY 4.0, 427 images in train split, classes: ['8', 'Calculus', 'CalculusCavities', 'CalculusHealthy Teeth', 'Cavities', 'Gingivitis', 'Healthy Teeth']). Used strictly to mine healthy-only images that trigger false positives in `best.pt` (MODEL_FALSE_POSITIVE) and clean normal controls (CLEAN_CONTROL) for YOLO v2 refinement. Mixed disease+healthy (144) and disease-only (268) images are excluded; approved negatives receive empty (0-byte) labels in v2 train |
| Roboflow Universe Penyakit Gigi Skripsi dataset | **OFFLINE TRAINING ASSET (CC BY 4.0)** | Large auxiliary healthy negative and clean control training source (Phase 11B-4 FINAL; URL: https://universe.roboflow.com/nathan-asif-blm21/penyakit-gigi-skripsi-i77mi/dataset/dataset, workspace: `nathan-asif-blm21`, project: `penyakit-gigi-skripsi-i77mi`, version: `dataset`, license: CC BY 4.0, 2,468 total images: train 1,974, valid 247, test 247; classes: `['calculus', 'caries', 'healthy']`). Used strictly for offline hard-negative / healthy-control candidate mining (129 false-positive candidates $\ge 0.30$, 55 auto-eligible clean controls). Mixed annotations (1,342) and disease-only annotations (788) are excluded. Runtime use: none. Note: Provided by a Roboflow user; not clinically validated |
| Vercel | **TARGET** | Frontend hosting |
